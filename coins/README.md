# coins/ — two-layer coin configuration model

This directory holds the fork's coin configuration. The model is
two-layered so that upstream data can be refreshed without touching
fork-specific entries:

```
coins/upstream_coins        byte-exact copy of KomodoPlatform/coins (branch
                            master), pulled and refreshed occasionally
coins/elektron_overlay.json fork-specific entries, wins on ticker collision
coins/elektron_coins        generated by scripts/elektron/coins_merge.py
                            -> point MM_COINS_PATH at this file
```

Regenerate the merged file:

```sh
python3 scripts/elektron/coins_merge.py \
  --upstream coins/upstream_coins \
  --overlay coins/elektron_overlay.json \
  --output coins/elektron_coins
```

The overlay wins per ticker (exact replacement, not field-wise merge).
The output is deterministic: sorted by ticker, 2-space indent.

The merge script validates overlay entries (required fields, supported
`protocol.type`, segwit entries need `bech32_hrp`), so config mistakes
surface at generation time instead of activation time.

## elektron overlay entries

| Ticker | Chain | Notes |
|---|---|---|
| `ELEK` | Elektron mainnet | segwit, HRP `be` (chainparams.cpp:222), 60 s blocks, coin type 1370. Native mode: pass `confpath` at activation; rpcport 8332 default. Electrum servers are passed per activation request. |
| `tELEK` | Elektron testnet | HRP `tb` (chainparams.cpp:314, testnet4 section). rpcport 18332. UNVERIFIED: base58 prefixes (111/196/239) not yet checked against `CTestNetParams` — check before testnet use (Phase 4). |
| `rELEK` | Elektron regtest | HRP `bcrt` (chainparams.cpp:662), rpcport 38332. Own `elektrond -regtest` datadir, conf path passed at activation. |
| `rBTC` | Bitcoin regtest via own elektrond instance | A second `elektrond` regtest datadir configured with BTC-like regtest params (pubtype 0, HRP `bcrt`), rpcport 18443. Labelled `rBTC` to make clear it is our own instance, not real Bitcoin. |

All four are `protocol.type: "UTXO"`, segwit, `mm2: 1`.

`avg_blocktime` is in **minutes** (elektron: 60 s blocks → `1`).

## Upstream data refresh

`coins/upstream_coins` is a snapshot, not a submodule. To refresh:

1. Download the raw `coins` file from `KomodoPlatform/coins` (branch
   `master`).
2. Replace `coins/upstream_coins` (keep byte-exact, no edits).
3. Re-run the merge script.

Diff-only-data rule: the snapshot must stay unmodified — fork-specific
entries belong in the overlay, never in the upstream snapshot.
